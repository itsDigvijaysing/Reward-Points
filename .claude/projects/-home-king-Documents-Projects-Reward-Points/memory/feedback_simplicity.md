Don't overcomplicate things unnecessarily.

**Why:** User corrected the initial plan which had percentage-based decay, XP multipliers, label bonuses, comeback bonuses, level formulas. User wants integer-only simple math: p1=4pts, 10pts=+1 stat, stats cap 100, streak-based ranking.

**How to apply:** Before adding any mechanic or calculation, ask "is this the simplest way?" If you're reaching for floats, percentages, or multipliers — stop and simplify. The RPG system should feel deep through its stat/rank/decay loop, not through complex math.
